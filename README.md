# Nuclear Cyborg Homebrew tap

Formulae for tools by [Andrew Benson](https://github.com/drewster99).

```sh
brew tap drewster99/tap
```

Or install without tapping first:

```sh
brew install drewster99/tap/<formula>
```

## Formulae

| Formula | What it is |
| --- | --- |
| [`safetensors-print`](https://github.com/drewster99/safetensors-print) | Print the header, metadata and complete data-segment layout of a `.safetensors` file |

Each formula is updated by its project's own release script, which pins the URL and
SHA-256 of that release's source distribution and reads the formula back from here to
confirm what landed.
